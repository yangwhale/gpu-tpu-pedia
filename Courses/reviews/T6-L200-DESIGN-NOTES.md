# 专题六 L200 设计笔记

L200（`WebPages/topic-06.html` ＋ `topic-06-lecture.html`）是从 L300 完整版（343′）里挑出来、用大白话重讲的 90′ 主线版。本文件记「为什么这样设计」；逐轮做了什么看 `T6-L200-STATE.md`。

## 一、起点：收成一个问题，讲透一条主线

样板是讲 DCP／PCP 区别的那三轮问答：听众抓不住重点时收成一个问题；用一条主线（「谁搬家」）把机制讲透；说清为什么会反过来（谁小搬谁），再落到后果（加不加卡）；被追问细节就回源码核实再答。L200 每一节都照这个形状写。

## 二、问题链（十节）

每节标题就是听众会问的那句话；开头接住上一招留下的洞，结尾报这一步进步多少（带口径）：

零 推理为什么贵 → 一 为什么首字快后面慢 → 二 多拉几个人（batch）→ 三 KV 占多少、怎么省 → 四 多卡 TP 还是 DEP（含大 EP）→ 五 长上下文 DCP／PCP → 六 PD 分离 → 七 投机解码 → 八 量化 → 九 第一天先问哪几问。

- 终点落在第九节揭晓「同硬件同模型、光改软件是首发日的 5.1 倍」，前面各节不许提前说出这个数。
- 第零节立两条路「多坐人、少搬货」，后面每一招都归到其中一条；唯一不碰这一趟的是 PD 分离，第六节回指（R13 修掉的矛盾）。
- L300 的时间线、关键事件、关键优化点是骨头，不丢；L200 改的是挑哪些讲、怎么讲。不进 L200 的：指标口径细节、两块硬骨头、双微批／EPLB、AFD／EPD、拓扑选法、状态快照、TPU 落地编排、台账。

## 三、比方体系：公交 / 笔记 / 厨房

一堂课只用三套比方，各管一段，互不打架：

| 比方 | 管哪几节 | 对应 |
|---|---|---|
| 公交车 | 零–二、四、七、八 | 开一趟＝decode 一步（搬一遍权重）；乘客＝请求；座位＝KV；随上随下＝连续批 |
| 每人一本笔记 | 三–五 | 笔记＝KV；一页多厚＝MLA／GQA；按页分座＝分页；复印几份＝TP 下 KV 重复；谁搬家＝DCP／PCP |
| 厨房 | 六 | 大锅菜＝prefill，出单碗＝decode，端半成品＝KV 传输；明说「这里换比方」 |

- 比方改过的地方：第二节「网约车拼单」和公交打架，R13 改回公交；零、一节「货随人涨」与「油钱固定」自相矛盾，R14 专家评审指出后统一口径。
- 缩写先拆名字（判据 8）：TEP／DEP 首字母＝注意力怎么切；DCP／PCP 首字母＝阶段，第四、五节各一个「名字拆开读」框。

| 判据 | 落地方式 |

## 六、淬炼口径校正的教训

R22 给课件和讲义定了同一个删字比例，讲义台词一轮掉 33%，全课含互动掉到约 78′：必要的「为什么」、评审补的铺垫、借来的讲法被一起删掉。R23 起分开：

- 课件正文以删和合为主，每轮 −10% 以上；
- 讲义只去真重复（两块说同一件事、复述屏幕或图上已写的、同一数字说两遍），不定比例；
- R24 口播轮把零到四节删掉的「为什么」补回。

一句话：课件要瘦，讲义要顺；对讲义用删字指标会把讲透的部分当冗余删掉。

## 七、借讲法：采纳与拒绝原则

R19–R21 联网读讲得好的人怎么讲，存档在 `T6-L200-R19/R20/R21-borrow.md`（外部作者名只在存档里）。原则：

1. **只借讲法，不借数字。** 开场、比方、讲述顺序可以借；数字以 L300 课件为准。
2. **比方必须和公交／笔记／厨房兼容。** 新比方单看再妙，和已有体系打架、或只是叠加一层又不省字，就拒。
3. **深度属于 L300 的拒。** 例：便宜卡跑 decode、早拒、配比漂移等，没有余量或属 L300 深度。
4. 借的只动讲义口播，课件不动；出处写在讲义构建脚本文件头注释。
