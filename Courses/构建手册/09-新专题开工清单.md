# 09 · 新专题开工清单

> 从零到上线，照着勾。每一步后面标了详细说明在哪一篇。
> 以「专题 N」为例；文件名里的 `0N` 换成实际编号。

---

## 阶段 0 · 定调（写一个字之前）

- [ ] 读一遍 `DESIGN-NOTES.md` 和 `README.md`（课程总大纲），确认这一讲在因果链上的位置：它回答前面哪一讲留下的问题，又给后面哪一讲留下问题。（[01](01-理念.md)）
- [ ] 翻 `专题0N-*.md` 大纲里之前别的专题已经存进来的材料。（[01 · 六](01-理念.md#六材料当场写进它该属于的那一讲)）
- [ ] **写下一句话主线**。写不出来就别往下走。（[03 · 三](03-四个保证.md#三故事性一讲是一个故事不是一份目录)）
- [ ] 列出各节，每节写一句「它回答上一节留下的什么问题」。检查有没有哪一节是「接下来介绍另一种 X」。
- [ ] 选标的：一个真实模型或真实系统，所有数字能对回 config 或一手来源。
- [ ] 列出承重词（后面好几处结论要靠它的词），规划在哪里第一次定义。
- [ ] 在 `DESIGN-NOTES.md` 记下这一讲的定调和取舍理由。

## 阶段 1 · 搭骨架

- [ ] 复制 `tools/topic05-build.py` 为 `topic0N-build.py`：改 `make_head` 的标题／描述／文件名，清空 `BODY` 和 `FIGS`，文件头写主线和「核对过的事实」。（[02](02-架构.md)）
- [ ] 第零节放一个术语框（折叠，「遇到不认识的词，回这儿查」）。
- [ ] 最后一节放出处台账（先建空表，边写边填）。
- [ ] 在 `build-all.sh` 加「专题 N 教材」一步（图脚本用 glob 跑，不手写清单）。
- [ ] 在 `WebPages/index.html` 登记这一讲，状态写「🚧」。
- [ ] 跑一次 `python3 topic0N-build.py`，确认空页面能生成。

## 阶段 2 · 逐节写（每一节重复）

- [ ] 先想这一节的图：原理能不能画出来？「把字删掉还剩什么」？（[04 · 一](04-绘图.md#一理念图是用来画原理的)）
- [ ] 需要「时间」或「第三维」才做动画，否则静态图。（[04 · 四](04-绘图.md#四manim-动画)）
- [ ] 从 [模板/fig-模板.py](模板/fig-模板.py) 起一个 `topic0N-fig-<小节>.py`：
  - [ ] 数字在脚本顶部现算，每个关键数字一条窄断言，能对外部锚点的都对上
  - [ ] aria-label 写完整描述
  - [ ] 读图钥匙放副标题；落点带最多两行；口径和免责进 `src()`
- [ ] 在 `FIGS` 表登记占位符、文件名、脚本名、图注（一句看哪里 ＋ 一句补充）。
- [ ] 正文只留图给不了的东西：前因后果、接力到下一节。不复述图注。
- [ ] 每一个数字、每一个架构说法：查过的写出处，推出来的标「本课推导」并给推导链，估算标「估算」。填进台账。（[03 · 二](03-四个保证.md#二准确不确定就查绝不编)）
- [ ] 碰到属于别的专题的材料，当场写进那个专题的大纲。
- [ ] 构建，**截图看这一节的每张图**。（[04 · 五](04-绘图.md#五目检)）
- [ ] 关着所有折叠读一遍这一节：通顺、不缺前提？
- [ ] 提交（只 add 自己改的文件）。

## 阶段 3 · 讲义

- [ ] 复制 `tools/topic05-build-lecture.py` 为 `topic0N-build-lecture.py`。（[05](05-讲义.md)）
- [ ] 每节：🎯 只留一句 → 台词（每块 ≤200 字）→ 屏幕提示 → 互动 → ⚠️ 别讲什么／备答。
- [ ] 页首写「上台之前」的暗线和「只能带走一句话」。
- [ ] `PLAN` 时间表；节标题分钟与之一致。看地板表，超了的节决定砍什么。
- [ ] 在 `build-all.sh` 加「专题 N 讲义」一步（排在课件之后）。
- [ ] 登记：`topic02-lint-cues.py` 的 `PAIRS`、`course_ai_trainer.py` 的 `DECKS`；课件开头调用 `AIT.note(...)`。
- [ ] `bash build-all.sh`，对账全过。

## 阶段 4 · 评审十轮（[06 · 三](06-评审与迭代.md#三两阶段迭代协议)）

- [ ] 建追踪文件（[模板/追踪文件模板.md](模板/追踪文件模板.md)），写下现场原话和轮次安排。
- [ ] 每轮先跑 `脚本/course-metrics.py`，再并发派两副眼镜（任务书见 [模板/评审任务书.md](模板/评审任务书.md)）。
- [ ] 逐条核实：认现象不认根因；几何类必须截图看。
- [ ] 按优先级修：静默 bug → 一词两义 → 承重词 → 复述 → 加粗 → 重画。
- [ ] 修基元不修实例；新判据做成断言。
- [ ] 构建 → 提交 → 追踪文件记一行 → 发通知 → 下一轮。
- [ ] 最后一轮收敛：只报剩余严重问题并打分。

## 阶段 5 · 边讲边改二十轮

- [ ] L1–L(节数)：一节一轮，讲师 agent 完整口播，报讲不顺、要临场补话、图不够用、说错的地方。
- [ ] 全篇串讲一轮：只看衔接与节奏，删重复接力，决定台上跳过什么。
- [ ] 第二遍换自学视角：讲义里好用的讲法补回课件。
- [ ] 整本自学通读一轮。
- [ ] 讲义↔课件终稿对账一轮。
- [ ] 最后一轮：所有图逐张截图目检 ＋ 全量构建。

- [ ] 循环接缝全绿；`course-metrics.py` 无静默失败、加粗 ≤30%。
- [ ] `WebPages/index.html` 状态改为「✅ 课件 ＋ 讲义」，加讲义链接。
- [ ] 公开仓库闸门：没有内部链接、没有个人信息（源码也算）。
- [ ] 提交、推送。
- [ ] 在 `DESIGN-NOTES.md` 补记这一讲过程中推翻过什么、为什么。
- [ ] 这一讲新踩的坑、新立的规矩，补进本手册对应的篇章。
