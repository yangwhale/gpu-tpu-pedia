## 阶段 1 · 搭骨架

### 1.1 复制课件脚本，并改掉所有写死专题五的地方

`cp tools/topic05-build.py tools/topic0N-build.py`，然后逐项改（行号是专题五脚本里的大致位置）：

| 改什么 | 专题五里长这样 | 说明 |
|---|---|---|
| 文件头 docstring | 主线、「核对过的事实」 | 换成这一讲的主线和事实 |
| `OUT` | `"topic-05.html"` | 输出文件名 |
| `make_head(...)` 的**四个**参数 | 标题、og 标题、og 描述、文件名 | 第四个要跟 `OUT` 一致 |
| 自带的 `<style>` | `.kind`、`.animgrid` 等 | 用得上就留，用不上删掉 |
| `SECTIONS` | `("s零", "零", "一张卡装不下")…` | 每节一行，跟 `BODY` 里的 `sec(...)` 一一对应 |
| `HERO` | 面包屑「主线 ／ 专题五」、讲义按钮 `topic-05-lecture.html`、`<h1>`、钩子、前置 chip、「讲约 48 分钟」 | 全部换掉 |
| `AIT.note("topic-05-lecture.html")` | 在 `HERO` 末尾 | 见下面 1.2 |
| `BODY` | 全部正文 | 清空，按 [02 · 六](02-架构.md#六正文怎么写html-词汇表) 的写法重写 |
| `FOOT` | 「上一讲」链接、脚本名 | 换成这一讲的 |
| `FIGS` | 各图的四元组 | 清空，边画边加 |
| 最后一行 `P.finish(..., "topic-05.html")` | 标签 | 换成这一讲的文件名 |

### 1.2 「把讲义丢给 AI」那一格，现在就要决定

复制来的 `AIT.note("topic-05-lecture.html")` 有两种结局：不改，页面会静默链到专题五的讲义；改成 `topic-0N-lecture.html`，
会立刻报 `没在 DECKS 里登记`。所以这一步不能拖到写讲义时：

- [ ] 在 `tools/course_ai_trainer.py` 的 `DECKS` 里加 `("topic-0N.html", "topic-0N-lecture.html")`，`AIT.note` 改成新讲义名
- [ ] 讲义还没写出来之前，这一格和讲义按钮是死链。二选一：**先把 `AIT.note(...)` 和讲义按钮删掉，写讲义时再加回来**（推荐），或者接受这段时间的死链、不要推送

### 1.3 登记（手动的只剩这几处）

- [ ] `tools/build-all.sh`：加一步「专题 N 教材」。照专题三的写法：先 `rm -f fig<N>-*.svg`，再 `for f in topic0N-fig-*.py; do python3 "$f"; done`，再 `python3 topic0N-build.py`。
      放在 `if [ "${1:-}" != "--lint" ]` 那个块里、专题二 L300 之后、`topic-repalette.py` 之前。
- [ ] `WebPages/index.html`（手写页面）：这一讲的状态写「🚧」。照着现有专题的格式抄一块。
- [ ] 配色收尾 `topic-repalette.py`：要不要把新页面加进去是判断题 —— 新专题都走 `topic03_draw` 基元，一般不需要（专题一、三就没加）。
- [ ] 不用登记的：版面、可读性、跨节指针三个体检和产物清单，2026-09-25 起从 `WebPages/` 目录现取页面。
- [ ] 跑 `python3 topic0N-build.py`，确认空页面能生成；再跑 `bash build-all.sh` 确认整条链不挂。

### 1.4 页面上两块固定内容

## 阶段 3 · 讲义

### 3.1 复制讲义脚本，并改掉写死的地方

`cp tools/topic05-build-lecture.py tools/topic0N-build-lecture.py`，逐项改：

- [ ] `OUT`、`DECK`（文件开头）
- [ ] `<title>`、og:title、顶栏的 `who`（「专题五 · 并行策略」）
- [ ] 顶栏导航里写死的「专题四（那张 16 字节的账）」

- [ ] `CH` 各节五元组、`PLAN` 时间表（节标题里的分钟必须等于 `PLAN`，有断言）
- [ ] 合计行里的「第九节（出处台账）不进课堂」
- [ ] 末尾 `print("ok  topic-05-lecture.html …")`

### 3.2 两个硬坑

- [ ] **「🚧 这份讲义还薄的地方」那一节不能删、标题不能改。** 时间账用 `html.index("🚧 这份讲义还薄")` 当最后一节的切分点，删了就 `ValueError`。讲义写完了也留着这一节，写「目前没有」。
- [ ] 节标题统一写成「第零节…第九节、第十节」。节号正则 2026-09-25 起认到「十」；超过十节要再放宽。

### 3.3 检查复制过来的断言

从专题五复制已经带着：节数对账、节标题分钟＝计划、「可压到」≥ 地板、TiB／GiB 大数对账、`anim-*` 对账、台词 200 字上限、
舞台提示泄漏、收尾语气位置、**课件封面「讲约 N 分钟」＝ 计划表**、台词数字密度（白名单 `_JUDGED` 清空重判）。

- [ ] 如果这一讲的图用 Ⓐ Ⓑ Ⓒ 标面板，从 `tools/topic04-build-lecture.py` 补上「一块台词不许跨两个以上面板且超过 90 字」
- [ ] 课件里也照专题五加 `_NUM_LOCK`：正文里手打的关键数，必须在对应的图里出现

- [ ] 看地板表，超了的节决定砍什么。
