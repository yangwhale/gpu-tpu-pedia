> ① 算出自己那块权重的梯度 —— 用这个敏感度，**乘上**前向时存下来的输入。
> ② 算出该继续往下游传的敏感度 —— 用这个敏感度，**乘上**自己的权重。

我完全接受「两件事各一次矩阵乘，所以 1+2=3」这个数数逻辑 —— 那一步讲得非常好。但我停在了「凭什么是这两个东西相乘」。1.4 讲了「偏导数是局部的」，1.5 讲了「为什么从后往前」，**都没有回来补这一句**。

所以「看激活规模」这个解释**没有解释掉这个反常**，它只是把 671B 换成 37B，而 37B 依然对不上。我在这里停住了，往后读了两小节还在想这件事。

## 五、关于你特别关注的那五件事 —— 逐一交卷

### ① 「反向传播为什么能把三千亿次前向压成一次」→ **讲清了八成，缺最后一句**

做得好的：1.1 先算笨办法（三千亿次前向 = 一万年）**是全讲最有效的一个设计**。我读到「而这还只是一步」的时候，真的坐直了。1.5 的「多输入、单输出」和那条可迁移判据（「先数一下输入多还是输出多」）也非常干净。

缺的是**收口那一句**。全文从没有一句话说：「反向走完一遍，三千亿个参数的梯度**全都有了**」。1.3 说每层做两件事、1.5 说 loss 只有一个数所以一遍就够 —— 但「一遍」和「三千亿个导数同时到手」这两件事没有被显式焊在一起。而这正是 1.1 提出的那个问题的答案。

**建议**：1.5 的 `.note.ok` 末尾加一句：「⭐ 所以那三千亿次前向，压成的是**一次反向** —— 反向走到第一层的时候，三千亿个梯度已经全部在手里了。这就是 1.1 那个问题的答案。」

### ② 「偏导数为什么让求导变容易」→ **这是五件事里最没兑现的一件**

§1.4 的标题是「为什么**偏导数**一出现，这件事就变容易了」，第一句是「⭐⭐⭐ 因为偏导数是**局部**的」。然后：**「偏导数」这三个字在这一节里再也没出现过。**后面全在讲「每个算子写一个 backward，框架倒着串一遍」和「链式法则不用展开」。

这两件事都讲得好 —— 但它们是**自动微分**和**链式法则**的道理，不是偏导数的道理。作为外行，我读完 1.4 能复述「自动微分是模块化的」，但我答不出「偏导数为什么让事情变容易」。

缺的那一环具体是：**「偏」字的意思是「其它全按住不动，只动这一个」**，正因为其它都按住，这个导数才只跟这一个算子的局部行为有关 —— 所以才「局部」。这句话现在不在文里，而它是整节标题的兑现。

**建议**（这是我认为投入产出比最高的一处改动）：在 L1001「因为偏导数是局部的」和 L1003 之间，插一段：

> 「偏」这个字就是关键。普通导数问的是「这个东西变了，结果变多少」；偏导数问的是「**其它全部按住不动**，只动这一个，结果变多少」。
> 正因为其它都按住了，这个问题就缩到了一个算子身上 —— 它不需要知道外面的世界长什么样。**这就是「局部」的意思。**

加上这 3 句之后，紧接着的「每一个算子只需要知道我自己是怎么把输入变成输出的」才是被**推出来**的，而不是被**宣布**的。

### ③ 「量纲 / 折算系数」→ **点子极好，缺一个补丁**

「两边的单位对不上」这个切入我非常喜欢 —— 它把「学习率为什么难调」从玄学变成了一句能记住的话，而且后面 Adam（量纲被除掉）→ 0.2 常数 → Kimi K2 拿 0.2 当接口，这条线**一路连到底，是全讲结构最完整的一条线索**。

两个小问题：

- **「loss 的单位」是什么？** L1785 说「梯度单位是 loss ÷ 参数」，L1788 反推出「学习率单位是 参数² ÷ loss」。可 loss 在我心里就是个纯数字（一个「差多少」的分数）。当一个「纯数字」被当成量纲用时，外行会觉得被绕了。**一句括注就够**：「（loss 本身没有物理单位，但它有**尺度** —— 换个 loss 函数、换个归一化方式，它整体大一倍，梯度就整体大一倍。这里说的『单位』指的是这个。）」
- **「update RMS」这个词，用了 4 次才被解释。** 它在 L1824 首次出现（「Adam 的 update RMS 稳定在 0.2～0.3」），而它的人话定义要到 L1850 才出现（「每一步每个参数大约挪 0.2 × 学习率」）。中间夹着一个闭式解和两个 bullet。**把 L1850 那句提到 L1824 前面**，这一段的可读性会明显不一样。

### ④ 「每参数 16 字节」这张账单 → **数字本身立住了，前提没立住**

fig-optimizers 的 Ⓑ 做得很好：五个方格、宽度跟字节数成正比（2 字节 152px、4 字节 304px，我量过，是对的）、右边一个「＝ 16 B」、下面直接给出「2 比 12，六倍」。这一格**一眼就懂**。

问题全在它的入口：
- 「混合精度训练」未定义（见 1.1）—— 这是最大的那道坎。
- 「二阶矩 v」这个词在 Ⓑ 里直接当标签用（L1677「fp32 二阶矩 v」）。而「二阶矩是什么」要到 §3.3（L1806-1812）才隐约说明白（「除以历史梯度平方和的根号」）。Ⓑ 在 3.1，§3.3 在两屏之后。
- 「16」这个数被口径换了三次而没有统一提示：16（经典口径）→ 18（梯度用 fp32 累加，L1736）→ V3 实际不是 16（L1749-1751）→ 12（Muon）→ 14（3.7 那个分母，见 4.6）。**每一次换都有理由**，但读者手里没有一张「现在我们在用哪个口径」的锚。

**建议**：在 3.1 的 Ⓑ 下面加一句定调：「⭐ 下文凡是说『16 字节』，指的都是这个经典口径。后面会出现 18、12、10 几个变体 —— 它们都是在动这五格里的某一格，回头对着这五格看就行。」

### ⑤ fig-muon 的「同一个动作的三个版本」→ **Ⓐ 成立，Ⓑ／Ⓒ 不成立**

- **Ⓐ 我看懂了**，而且是靠图看懂的：四根高矮不齐的白条 → 四根一样高的紫条，配「方向全留下，大小全扔掉」。即使我不知道「奇异值」是什么，我也接收到了「有一组数被抹平」。**中间那列（对角阵）作为桥也搭得好** —— 三列并排，我确实感觉到了「这是同一件事在三种形状上」。这一格的设计是成功的。
- **Ⓑ 我没看懂**（见 1.2）。「迹 / 相似变换 / 特征值」三连，而这一格承担的是全图最重的那个问题：「矩阵和向量不都是一堆数字吗」。
- **Ⓒ 我没看懂**（见 1.2）。「F 范数 / 谱范数 / 诱导」。但 Ⓒ 想说的那句话（「换一把尺子量，就换出一个优化器」）**我在正文 L2017 读懂了** —— 因为那里用的是「差别只在拿哪把尺子量『这一步迈多大』」，没有「诱导」这个词。**正文那句比图上那句好懂**，说明这一格的文字可以直接照正文改。
- **Ⓓ 我看懂了，而且很喜欢**：三个色块（算梯度 / 空窗 / 算下一步梯度）+ 下面挂一个「msign 就干在这儿」。这一格回答了我心里真实存在的疑问（「多做十几次矩阵乘不会很慢吗」），而且用的是一个纯时间轴，零术语。

另外：**fig-muon 是全页最高的一张图（viewBox 1668，比第二高的 fig-optimizers 还高 328）**，四个面板。如果要瘦身，Ⓑ 是第一候选 —— 它是四格里唯一一个既看不懂、又不承重的（去掉 Ⓑ，Ⓐ→Ⓒ→Ⓓ 的链条完全成立）。

## 六、写得特别好的地方，以及**为什么**我懂了（这部分建议当模板用）

### 6.1 「先算笨办法」—— §1.1
> 「我想知道某个参数对 loss 有多大影响，就把它动一丁点，整个网络重跑一遍前向，看 loss 变了多少。……三千亿次前向。一次前向按一秒算，跑完要将近**一万年** —— 而这还只是**一步**。」

**为什么有效**：它先让我**能自己想出那个笨办法**（有限差分谁都能想到），再让我自己算出它有多荒谬。等到反向传播出场时，我已经在心里给它开出了价 —— 而不是被告知它值钱。

而且这符合它自己写在源码注释里的判据（L851）：「先问『难在哪』，再讲『怎么解』」。**这条判据在 §1.1、§2.3、§3.3、§6.3 都用了，四处都是全讲最好读的段落。** 这是可复制的。

### 6.2 「第一个梯度 ＝ 你猜的，减去正确答案」—— §1.2
一句话，零术语，而且它替代了一整页 softmax + 交叉熵求导。后面那个 `.sub`（「不是所有 loss 都这么好看，但这一对是今天的默认组合」）把简化的边界也交代了，我没有被骗的感觉。

**可复制的做法**：给一个**不带任何符号**的结论句 + 一个小字的「这个简化在什么条件下成立」。这一讲全篇都在用这个格式，用得好的地方（1.2、2.3、3.2）比用得少的地方（3.3 后半、fig-muon Ⓑ）好读一大截。

### 6.3 「两条斜率不同的线，必然相交」—— §2.3-2.5 + fig-per-byte
这是**全讲最好的一段**，我读的时候有「啊」的那一下。三个原因：
1. 它先给了一个我自己能验算的闭式解（`每字节代价 = k`，S 和 n 全约掉）；
2. 它用这个判据排出一张表，然后**拿 DeepSeek 的实际配置去对**（L1441-1448）—— 「判据是我们自己推的，但推出来的名单跟人家实际配的对上了」，这一句让我彻底相信了前面所有推导；
3. 它拿同一条判据去打 2022 年那篇论文，发现结论相反，然后指出**变的只有一根竖线**。

**这三步（自己推 → 拿外部证据对 → 用它解释一个历史反转）是这一讲最值钱的叙事模板。** 建议在别的讲里复用。

### 6.4 附录 §7「查得到出处的 / 自己推的」
这一节我读完专门回去重读了一遍。**「它可能错在哪」那一列是神来之笔** —— 它把「这个数可能不准」从一句免责声明变成了一条可执行的信息（比如「⛔ 换一条线性层做对照，交点就不同」）。

而 L3035-3038 那段（82.1% 之所以可信，不是因为算得仔细，而是因为专题一用**完全独立**的另一套算法给出了 81.8%）—— 这是整份材料里我最愿意转述给别人的一句话。

### 6.5 「⭐ 这一小节可以整段跳过」—— §1.7 开头
一句话就解决了难度落差。我照做了，跳过之后无缝接上 1.8，一点不适都没有。**这个动作全页只用了一次，但该用的地方还有至少两处**（fig-muon 的 Ⓑ、§3.6 的 PaLM β₂ 那一整段）。

### 6.6 §6 整节
第六节是全讲对外行最友好的一节：Ⓐ 三张卡（治结构 / 治数值 / 治现场，从左到右越来越应急）给了一个**我一眼能记住的骨架**；6.2 那个消融（同一批数据换个时刻喂就不飞）是个完整的小故事；6.3 那张三行表的中间一行（「稳定 3/3」但质量 −4.206）是个**反直觉但一看就懂**的证据。

而且 6.7 明说「那三类不是并列的选项 —— 它们有先后」，正面回应了 Ⓐ 图注里那句「技巧清单列完了，读者还是不知道该先动哪个」。**提出问题 → 图 → 正文兑现**，闭环干净。

## 七、如果只能改 5 个地方

按「改了之后对新读者帮助最大」排：

**第 1 名：把 figonly 默认关掉（或加一条顶部横幅告诉读者当前是折叠态）**
位置：L3075 `set(saved === null ? true : saved === "1")`。
理由：这是唯一一条「改一个字符，影响整页」的。现在陌生读者第一眼看到的是一份**被挖空的**教材 —— §1.2 整节不见、§3.2 整节不见、九张图的图注全不见。上面那六十条反馈里，有相当一部分内容其实写得很好，只是第一次打开看不到。
成本：一个布尔值。

**第 2 名：§1.4 补上「偏」字的那三句话**
位置：L1001 之后。
理由：这是你点名要讲清楚的五件事里**唯一一件完全没兑现的**（标题写的是偏导数，内容讲的是自动微分）。而缺的那一环只有三句话：「偏 = 其它全按住不动，只动这一个 → 所以问题缩到一个算子身上 → 这就是『局部』」。加上之后，1.4 的标题、1.4 的第一句、1.4 的正文第一次连成一条因果链。
成本：三句话。收益：让全讲最核心的那个「为什么」从「被宣布」变成「被推出」。

**第 3 名：修 fig-step Ⓐ 的高度比例（或者干脆取消高度比例）**
位置：L2544-2552。
理由：它是「全专题的收口图」，而它目前把 1.22 TiB 的梯度画得比 7.32 TiB 的优化器状态还高（96px vs 78px），**直接把这一讲的主结论画反了**。读者花两个小时被说服「最大的一块是优化器状态」，然后在收口图上看到相反的东西。
成本：改几个 rect 的高度，或者加一句「⚠️ 各条高度不成比例，看标注数字」。
（这条的判据是我量的 SVG 坐标，写在 §二.2.1 的表里；如果 build 脚本里本来就有 assert，值得顺手加一条「高度/数值比在四项间一致」的断言。）

**第 4 名：把 §3.1 的「混合精度」入口补上 + 统一 16 字节的口径提示**
位置：L1581 前。
理由：「每参数 16 字节」是这一讲的招牌（写在 og:description 里），而它的第一句话就用了一个未定义的前提词。两句人话（「同一个参数存两份：省地方的 bf16 给算用，精确的 fp32 用来记账」）能把 3.1 / 3.2 / 3.7 三个小节一起解锁。再加一句「后面会出现 18、12、10 几个变体，都是在动这五格里的某一格」，能止住 §3 到 §5 之间那连续四次口径切换带来的晕眩。
成本：三句话。

**第 5 名：修四处会让读者怀疑自己的硬伤**
这四条单独看都不大，但它们的共同点是**读者会以为是自己读漏了**，然后往回翻 —— 这是最消耗信任的一种卡壳。
1. §5.2「第二节算过 82.1%」→ 第二节没有这个数（L2630）。
2. §4.1 说梯度第四大 / §4.2 说梯度「次大」（L2463 vs L2481）—— 而 4.2 整节的论证就是「把 4.1 那个顺序倒过来读」。
3. fig-3x 后面那段「图 Ⓑ 那两张卡片的读法」，说的其实是下一张图（L1054，挪到 fig-act-bill 之后即可）。
4. 第二节以 1.7 / 1.8 开头（L1148、L1215）—— 编号说它属于上一节，位置说它属于下一节。
成本：四处都是搬动或改数，不需要重写。
