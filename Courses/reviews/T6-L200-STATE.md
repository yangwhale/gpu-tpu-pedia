# 专题六 L200 迭代追踪

## 原话（2026-10-19 17:59 HKT，飞书语音）

> 其实刚才这种讲课的模式才是听众想要的：
> - 你得捡听众关心的内容，把它讲明白，用大白话的方式把它讲透。
> - 而不是按照你自己的全文逻辑，像流水账一样把所有东西都讲了，没有重点的那种。
>
> 所以你按照刚才这种讲课的维度，把整个课程都给优化一遍。现在是重大更新：
> - 把现有的课程和讲义改成 L300
> - 从中提取重要内容，改变讲课的风格（大白话为主）
> - 挑听众感兴趣的维度，按照刚才的讲课风格精炼地讲一遍（大概讲90分钟就差不多）
> - 生成一个 L200 的版本
>
> 一轮一轮的迭代着做，不用一次都做完，二三十轮都行。

「刚才这种讲课模式」＝ 讲 DCP 和 PCP 区别的那三轮问答：
1. 听众抓不住重点时，**收成一个问题**，只讲它；
2. 用一条主线把机制讲透（「谁搬家」：PCP 问题不动、KV 搬过来，答案不用拼；DCP KV 不动、Q 发过去，答案要拼）；
3. 说清「为什么会反过来」（谁小搬谁），再落到「加不加卡」这类后果；
4. 被追问细节（搬的是 Q 还是激活）就去翻源码核实，再用大白话答。

## L200 判据（每一节都要过）

1. **这一节回答一个听众真会问的问题**，标题就是那个问题。
2. **一个比方 ＋ 一条机制讲透**，其余数字只留能当锚点的一两个。
3. 讲「为什么」，再讲「所以呢」（后果、什么时候用、什么时候亏）。
4. 一段话换个位置照样成立 → 它属于 L300，不属于这里。
5. 讲义是大白话口播稿：短句、先给直觉、少报符号名；互动＝抛题、停一下、揭晓。
6. 事实只取 L300 课件；新查的事实先进 L300 再进 L200。

7. **L300 捋出来的时间线、关键事件、关键优化点是骨头，不许丢**（10-19 18:29 补充）：
   L200 改的是挑哪些讲、怎么讲（大白话、讲透），不是换一套内容。
   十节按问题链串：每节开头接住上一招留下的洞，结尾报这一步进步多少（带口径）；
   终点落到「同硬件同模型、光改软件是首发日的 5.1 倍」。

8. **常听说、却说不清的缩写，先拆名字再讲机制**（10-19 18:33 补充，现场举例）：
   三个字母一样长，拆法完全不同 —— DCP／PCP 的首字母是**阶段**（decode 的 CP、prefill 的 CP）；
   TEP／DEP 的首字母是**注意力那一半怎么切**（注意力 TP 或 DP，专家那一半都是 EP）。
   第四、五节开头各放一个「名字拆开读」框，并点一句两组命名维度不同；顺带提 TEP／DEP ≠ Megatron 的 ETP／EDP。

9. **重点示例（10-19 18:35 现场补充，都是 L300 已有的）**：第四节的大 EP 要讲透两件事：
   **① 好处**（L300 6.3：每份专家分到的行数 8→约 128、每层每卡读专家 1.41 GB→88 MB、路由专家显存 81.7→5.1 GB 腾给 KV）；
   **② 为什么做得成**（L300 6.4：每 token 一步只收发约 10 MB，难在延迟不在量；8 卡机＋IB 全互连＋GPU 直发 RDMA 也能做；NVL72 一柜 72 卡一个 NVLink 域，EP 铺几十张卡不出柜）。
   再落到「NVL72 这类大域对推理特别合适」：L300 现有锚点是 SGLang GB200 NVL72 对 H100 大 EP 每卡 2.7×（decode）、3.8×／4.8×（FP8 注意力＋NVFP4）。
   ✅ 10-19 拍板：**只用 L300 现有的对 H100 数，不另找 B200 对比**。L200 里不出现「比 B200 高 N 倍」。
   第四节内容变多，计划可能从 10′ 提到 12′，从别处挪。

10. **第七节投机解码必须讲 EAGLE 这一支**（10-19 19:10 现场追问「为什么没有最常用的 EAGLE」）：
   草稿谱系按「离大模型越来越近」一条线讲：独立小模型 → Medusa 加头 → **EAGLE 读隐状态（2024-01，LLaMA2-Chat 70B 2.7–3.5×）→ EAGLE-3 融浅中深三层（2025-03，单请求最多 6.5×、batch 64 仍 1.38×）** → MTP 训进主模型 → DFlash 一趟出整块（隐状态注入草稿每一层，EAGLE-3 只喂入口）→ DSpark。
   一句话分清：MTP 和 EAGLE 猜法一样（一个字一个字），差在 MTP 随主模型一起预训练发布、EAGLE 是事后外挂训练；EAGLE-3 是 vLLM／SGLang 上最常见的外挂草稿。各家倍数不能横比。
   ✅ 10-19 19:20 试讲追问后已写进 L300 11.3（六段＋讲义五块＋§十六四行出处）：EAGLE 要训但只训 FC＋一层 decoder（嵌入层、LM head 借大模型）、怎么猜、EAGLE-3 两处改动、MTP 结构与 EAGLE 几乎一样（差在谁训）、带 MTP 的各家、单层连猜接受率 70/10/0 → FastMTP 81/56/36。R10 第七节从这里取，重点讲「EAGLE 不是免训练」和「多猜几步要按连猜练过」两句。
