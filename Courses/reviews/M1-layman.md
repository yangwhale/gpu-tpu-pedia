# M1 · 完全外行（做产品的）

## ⭐ 核心断裂：loss 到底怎么算 —— 全讲没说

§1.2 第一句「loss 是一个数」之后**直接跳到它的梯度**。
grep 实证（已由主持人独立复核）：`交叉熵` 3 次且**每次只是一个名字**；
`负对数` / `−log` / `对数似然` / `困惑度` **全部 0 次**。

掉队点：§1.2 说网络吐出的是**概率分布**，§1.8 说一个 batch 是 **62.9M token**，
而 §1.5 的全部论证建立在「参数几千亿，**loss 只有一个**」。
**几千万个预测怎么变成一个数 —— 这一句全文没有。**
读者会以为「那一定是 batch=1 吧」，于是 §1.5（全讲最好的想法）不成立。

⛔ `fig-vote` Ⓒ 把读者推向错误答案：它画的是「所有人的诉求取平均 —— 那个平均就是**梯度**」。
平均的是梯度不是 loss，读者顺手合并成「loss 也是一堆数」。

**缺的就是三句话**（插在 §1.2「loss 是一个数」后）：
① 一个位置的 loss ＝ 看你给**正确那个字**打了多少概率，概率越低这个数越大（取对数、加负号）；
② 序列上每个位置各算一个，整个 batch 全部**加起来除以个数**；
③ 所以不管喂 1 条还是 62.9M token，**出来永远是一个数** —— §1.5 全靠这一条。

⛔ 同屏矛盾：§1.2 正文说「那个减**不是对概率求导，是对 logits 求导**」，
而紧跟的 `fig-vote` Ⓐ 画的柱子全是**概率**（0.30 / 0.20），箭头标「差 0.70」。后文不回收。

## 故事线：能复述论证，复述不出故事

能一口气讲完的是一条**会计报告**（前向半张账 → 反向 3 倍 ＋ 激活扔不掉 →
33% 换 97% → 最大的是优化器状态 → ZeRO 三级 → 还是会飞）。**但它没有时间轴。**

页面上真有三段历史，**从不相遇，而且两段被藏在折叠块里**：
1. 1991 Hochreiter 德文硕士论文 → Bengio 1994 → 2001 两拨人坐到一起
   —— 全篇最有戏的一段，写在 `fig-vanish` 的 `<details class="figsrc">` **默认折叠**里
2. 1964 Polyak 小重球 → 2011 AdaGrad → 2012 一页 slide 的 RMSProp → 2014 Adam
   （作者顺序掷硬币定的）→ 2017 AdamW → 2024 Muon 往回走一步 —— 细节也在折叠块
3. 2022 年论文说 attention 最该重算 → 2024 年同一条判据说它最不该重算（§2.4–2.5）
   —— 全页最像剧情反转的一段，却被当成「一处口径订正」写

**情节断在三处**：
- **§零第三段就剧透了结局**（「最大的那一块…是优化器状态」）。悬念在第 3 段用掉。
- **§4 和 §5 是唯一放下过的地方** —— 一个人物都没有、一个年份都没有。
- **§6 是全讲最像故事的一节，却排在最后。**「PaLM 训 540B，loss 飞了大约 20 次。
  而且 —— 梯度裁剪是开着的。」「论文说：没找到。」这是完美的冷开场。

## 五、⭐ 哪些一下就懂了 —— 可复制的做法

- **A. `fig-slider` Ⓒ 换汇比喻**：人民币→港币→美元。⭐ 判据：**找一个「结论对读者而言已经是常识」的类比，而不是找一个「像」的类比。**
- **B. §1.1 的笨办法**：三千亿次前向 ＝ 将近一万年，而这还只是一步。**先把代价量化成一个荒谬的数**，等 §1.5 说「压成一遍」时那不是知识点，是如释重负。
- **C. `fig-vote`**：把名词（梯度）换成**有人物的场景**，而且每一步都有理由 —— 是**因果推进**不是分类罗列
- **D. `fig-precision` Ⓑ**：一个数、一个操作、一个可证伪的结果，而且**把机制画出来而不是断言出来**
- **E. §3.7 checkpoint**：给的是**一个可以自己用的问题**，不是一个要记住的答案
- **F. `fig-circuit`**：整讲**唯一小到能用手验算**的地方 —— 验过一次之后，对前面验不了的话也一并信了
- **G. `fig-recompute` Ⓐ**：**先告诉读者能不能比**（两边都归一到 100%），给了比较的许可才敢下结论
- **H. §1.1 那一整格的存在本身**（花一格把三个词说完）—— 全课最该被复制的动作，只用了一次
