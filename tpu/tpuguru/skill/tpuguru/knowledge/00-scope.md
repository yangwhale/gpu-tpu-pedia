# ⚠️ 先读这篇：这些知识什么时候不适用

**所有数字都来自一个具体环境**。换了任何一项，**方向可参考，绝对值必须重测**。

| 维度 | 本知识库的取值 |
|---|---|
| 模型 | 295B 总参 / 21B 激活的 MoE，192 专家、top-8、80 层、hidden 4096、mlp 1536 |
| 硬件 | TPU v7（Ironwood），64 芯片 = 128 device |
| 框架 | MaxText（nnx），2026-08 的某个 commit |
| 序列长度 | 4096 |
| 数据 | 合成数据（固定种子，每步同一批） |
| 日期 | 2026-08-15/16 |

## 三级置信度

引用任何一条知识时，**先判断它属于哪一级**：

| 级别 | 含义 | 换环境后 |
|---|---|---|
| 🟢 **机制** | 代码逻辑、约束关系、失败模式 | **大概率仍成立**（除非上游改了代码） |
| 🟡 **规律** | 「加宽分片省显存」「通信藏得住才快」 | 方向成立，幅度会变 |
| 🔴 **数字** | 727.0、94.74 GB、2048 是甜点 | **必须重测** |

**说话时把级别带上**：
「机制上，切到组维会静默出错（🟢）；在我们那套配置上实测差 1.59 倍（🔴，你的环境要重测）」。

## 特别容易失效的几条

- **所有 per-chip 数字** —— 换模型必变
- **batch 上限** —— 跟模型大小、序列长度、精度全相关
- **tile 甜点值** —— 跟 hidden/mlp 维度绑定
- **编译器行为**（融合、能不能提升出循环）—— **跟编译器版本绑定**，
  这也是为什么镜像 tag 必须与生产一致

## 不会失效的

- 「不要看配置，要看行为」
- 「把 N 切成 N/k、下游能当合法小 N 用时会静默」
- 「短程 loss 测不出分片错误」
- 「手写集合通信牺牲调度自由度」
- 「主权重必须 fp32」

**这些是方法和机制，不是数字。**
