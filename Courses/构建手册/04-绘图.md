# 04 · 绘图：静态图与动画

> 这门课的主体是图。课件每处只留「一句 highlight、一张图、一句图注」，所以图画不好，这一处就是空的。
> 这一篇讲：什么样的图算画对了、怎么写一张图、视觉规范、什么时候做动画、怎么目检、踩过哪些坑。
> 代码证据都在 `tools/topic03_draw.py`（基元库）和各 `topic0N-fig-*.py`。

## 一、理念：图是用来画原理的

### 判据：把字删掉，还剩什么？

现场标准原话：

> 「图是图，字是字。图的目的是把原理画出来，让人一目了然，
> 而不是把本来该写在正文里的东西放进表格里 —— 那些表格不是图。」
> 「要跟现实生活中的世界结合起来，不要那么抽象。我们是大众课程。」
> 「图里的字不要太小，也不要太多，打到屏幕上去分享那样的图。」

可以直接执行的版本：**把图里所有文字删掉，剩下的形状能不能让人猜出这一格在讲什么？**
能，就是画出了原理；不能，就是一块写字的板子。
反面例子：三个框里的字删掉，只剩三个空方框和一个箭头。

逐图评审把每张图判为三档：✅ 画出了原理、⚠️ 半图半表、⛔ 写字板。`topic02-lint-figink.py` 量「删字后每一格还剩多少形状」做初筛。

⚠️ figink 的已知盲区：它只认「成组的」形状（曲线、一组高低不同的柱子、一组向量），不认**一格格同样大的方块靠颜色表达意思**的画法，也不认少量承重的条形。专题五的集合通信、ZeRO、KV 复制这些图正是这种画法，2026-09-25 体检时 20 张里有 11 张被判成「写字板」，大多是误报。**它只做分诊，结论以人看截图为准**；要让它认这一类，得加新的形状类型并用已判样本两头回归，不能放宽阈值。

### 几条具体的画法判据

- **每个盒子都该回答一个问题，而不是标一个名字。** 简陋的根因是每个元素只承载一个信息 ——
  读者付出了「看图」的成本，却没拿到「只有图才给得了」的东西。
- **要讲「有多少」，就别画「怎么连」。** 自注意力初版画成两排点加连线，n=6 就有 21 根线糊成一团，
  「平方长大」反而看不见；改成 n×n 的格子之后，总数是平方、因果遮罩遮掉哪一半、它就是注意力矩阵本人 —— 三件事同时出来。
- **一张图只回答一个问题。** 「顺便也讲讲」就是它开始讲不清的时候。拆图的切口由问题给出：一张图一个问句。
- **句子听起来像悖论时，图要把被混为一谈的两个量分开画**，而不是复述那句话。
- **表格不要画成图。** 39 行的参照表做成可排序的 HTML 表，只有时间轴留作 SVG ——
  把表画成图等于放弃搜索、复制、排序和无障碍。
- **脚本文件头写清：这张图回答哪一个问题、承重的数字从哪来；有刻意省略时，再写刻意没画什么**（免得以后有人「补全」）。例：某张示意图的轴上没有刻度，因为画上刻度就是编；流水线气泡图画的是 GPipe 调度不是 1F1B，因为两者气泡一样大、GPipe 更好看懂。
  给读者看的那一半写进图注的补充部分：「格数是示意」「画的是不带因果掩码的情形」。
- **全讲统一的画法先教一次**：专题五第一节 §1.1「先学会看图」把「四张卡四种颜色、条纹＝加过、虚线框＝空」先讲清，后面所有图照用，读者不用每张重学。
- **查阅用的表给一把读表钥匙**：告诉读者先看哪一列（例：「先看两个『不用』」），或者写明「第一次读可以直接跳到 §8.6」。

### 图、图注、正文的分工

| | 装什么 | 不装什么 |
|---|---|---|
| 图 | 原理的画面；标题一句话说结论；图例；最多两行落点带（换来了什么／代价是什么） | 长解释、口径说明、免责 |
| 图注 | 一句「看哪里」＋ 一句补充（第一个 `<br>` 后自动折叠） | 复述图里的字 |
| 正文 | 图给不了的东西：前因后果、接力到下一步 | 复述图注 |
| 出处与口径（图下折叠） | 数字来源、推导、口径、免责 | —— |

落点带第三行起、口径和免责类内容，收进「出处与口径」。判据：
**它是帮人看懂这张图的，还是帮人别误用这张图的？** 前者留在图上，后者收进去。

三方查重在构建时自动跑（连续 14 字重合就报）。还有第四种重复：同一张图的两个格子互相复述 —— 修法是把其中一格改成画。

## 二、怎么写一张静态图

### 技术栈

- 所有静态图走同一个基元库 `tools/topic03_draw.py` 的 `Fig` 类。
  抽成一份的理由不是代码复用，是**视觉一致性**：这门课的图必须看起来是同一个人画的；
  抄第二份，两套图会慢慢漂开，而且漂了不报错。
- 常用基元：`header`（标题 ＋ 副标题 ＋ 图例）、`panel`（带标题栏的面板）、`band`（落点带）、
  `src`（出处，折进图下的「出处与口径」）、`box / t / line / path / poly`、`cell`（两行字的盒子，主标签 ＋ 一句说明）、
  `spot`（高亮带）、`icon`（统一比喻图标）、`elbow`（圆角直角连线）。
- `Fig(w, aria)` 的第二个参数 aria-label **必填**：用一两句话完整描述这张图，给读屏用。

### 最小骨架

见 [模板/fig-模板.py](模板/fig-模板.py)（可以直接运行）。结构是：

```python
from topic03_draw import Fig, BL, OR, GR, RD, GY, INK
W = 1400

# ① 数字在最上面现算，并用窄断言钉住（跟外部锚点或别处的同一个数对齐）
RIDGE = 2307e12 / 0.6e12
assert abs(RIDGE - 3845) < 1, RIDGE

def fig_xxx():
    f = Fig(W, "给读屏用的完整描述……")                        # ② aria 必填
    y0 = f.header("标题：一句话结论　——　<tspan font-weight=\"700\">重点</tspan>",
                  "副标题：怎么读这张图（读图钥匙放在最上面，不要放在图底）",
                  [(BL, "图例一"), (OR, "图例二")])
    py = f.panel(0, y0, W, 300, "面板标题", BL)                 # ③ 面板里画原理
    ...
    yb = f.band(py + 320, "ok", "落点带标题", ["换来了什么", "代价是什么"])   # ④ 最多两行
    yb = f.src(yb + 10, "📌 出处一……", "⚠️ 本课推导：……")      # ⑤ 出处折进图下
    f.save("figN-xxx.svg", yb + 14)                            # ⑥ 完整文件名

fig_xxx()
```

### 数字必须是跑出来的

- 曲线和小球的位置要真跑一遍（例如梯度下降真迭代）。手挑位置等于把结论画上去，而不是让它自己长出来。
- 精度边界从位模式读出来；参数取自 `config.json`。
- 示意图里也要有硬骨头：按定义必然成立的那一段要真算出来。
- 与其手调参数到「看着对」，不如把「要满足的条件」写成筛子去搜一遍。

### `save()` 自带的检查

文件名必须带 `.svg`；共用图里不许出现本课节号；面板越界打印警告；
线宽在序列化出口统一吸附；写盘前用 minidom 做良构自检；没有出处时删掉旧的 `.src.html`
（否则上一次的出处片段还会被包进页面 —— 产物目录里的陈旧文件不会报错，只会安静地继续生效）。

## 三、视觉规范

每一条都有理由，理由在 `topic03_draw.py` 的注释里。

| 规范 | 内容 | 为什么 |
|---|---|---|
| 配色三档 | Material 50 浅底、500 主色、900 文字；`t()` 自动把 500 主色文字降到 900 | 高饱和主色大面积当正文色，是廉价感的头号来源 |
| 容器不填色 | 填色只给承载信息的小元素；大面积装饰色块会被自动去底 | 颜色用在小而多的元素上是现代，刷在大而少的整条带子上是土 |
| 面板样式 | 外框中性浅灰、顶部 4px 彩带、彩色标题字；落点带用左侧 4px 竖色条 | 实心色块＋白字是仪表盘观感 |
| 描边 | 默认 `#dadce0`，别把默认改深；要强调就显式传主色 | 跟专题一的主力描边一致（那边用了 287 次），不靠加重灰线来强调 |
| 字号 | 地板 11；正文长句天花板 17（超了报错，不静默钳位）；标题 20、副标题 15、图例 14；落点带 15 | 投屏看得清靠标题、副标题、图例撑起来，不是把每句正文都抬一档。静默钳位会让下一个人估错版面 |
| 投屏读数 | 整张图缩到 1280×720 后最小字低于 9px，就不能整张投，要一格一格放大讲 | `topic02-lint-projection.py` 给读数，讲义据此写「放大哪一格」 |
| 去装饰 emoji | `t()` 出口统一删掉，✓✕↑→ 这类几何记号保留 | 一个专题实测 613 个 emoji，是「PPT 剪贴画」观感的来源 |
| 统一比喻图标 | 同一个比喻在不同图里必须长同一个样子，统一用 `icon()` | —— |
| 连线 | 拐弯的连线用 `elbow`（圆角直角），别用两条 `line` 拼 | 硬直角是「简陋」的主要来源之一 |
| 等宽字宽度 | 估算文字宽度时 ASCII 要乘 `MONO_K = 1.12` | 图用等宽字体，实际步进比估算宽约一成；漏乘会让图例顶到下一个色块（专题五 L20 实例） |
| 读图钥匙 | 「怎么读这张图」放在副标题，不放图底 | 放图底，读者每次都先看错一眼 |

## 五、目检

**产物合法 ≠ 产物正确。** SVG 是良构 XML、几何 lint 全绿，浏览器里那张图照样可以是空的。
所以画完、改完，都要渲染成 PNG 用眼睛看。

### 怎么截

- **从成品页面里截，不要直接打开 .svg 文件。** 图是内联进 HTML 的片段，单独打开会显示成 XML 源码，
  或者字体退回 16px 衬线体 —— 看到的是假的。
- 用现成脚本：`python3 构建手册/脚本/shot-figs.py WebPages/topic-05.html`
  —— 用 playwright 打开成品页面，对每个 `figure[id^="fig-"] svg` 做元素截图，两张一拼存成 `/tmp/figshots/sheet*.png`，
  再用图片查看工具逐张看。专题五 L20 就这么把 20 张图逐张看了一遍，抓出三处重叠。
- 派审稿 agent 之前先跑 `构建手册/脚本/course-metrics.py`：它量出三类静默失败（见下）、投屏字号、加粗占比。
  能算出确切数字的，不要写进 agent 的任务里。

### 看什么

- 文字有没有被盖住、压线、顶出面板、跟别的字撞车
- 图例文字和下一个色块之间有没有空隙
- 标签离它指的东西够不够近
- 读图钥匙是不是在最上面
- 动画：首帧和末帧的拼接图

### 两条量图的纪律

- **从画面里量东西之前，先把取样框画出来看一眼。** 框错时量出来的数字看着完全正常。
- **盘点按渲染后的属性，不按 class 名。** 按名字建清单会漏掉命名体系之外的一整类。

## 六、图的反模式

| 症状 | 根因 | 修法 |
|---|---|---|
| 曲线整条没画，只剩空坐标系 | `path`／`poly` 收到了 Python 点列表，产物 `d="[(1.0, 2.0), …]"` 仍是良构 XML，浏览器什么都不画也不报错 | 基元接受结构化输入，并断言 `d` 以 `M` 开头 |
| 图的后半截凭空消失 | 内联 SVG 里写了 `<em>/<i>/<b>/<u>/<br>`，HTML 解析器当场退出 SVG 模式 | 只用 `tspan`；`t()` 黑名单断言；`build-all.sh` 全页兜底检查 |
| 关键句被擦掉 | 面板用了白色实心底，盖住了上一块画出界的内容。**跟背景同色的填充照样是一次覆盖** | 大矩形一律 `fill="none"`（一行改动救回 14 张图） |
| 字被裁掉，却没有滚动条 | 文字溢出不报错 | 所有「一整行文字」的基元自带宽度断言 |
| 宽图左边一截被裁，探针报 0 | 往左溢出不增大 scrollWidth | 量 `getBoundingClientRect().x < 0`；两个方向都要量 |
| 图里的字比正文还大 | `class="None"` 按 SVG 默认 16px 画 | 拿外部锚点比：图内字不超过正文 |
| `**粗体**`、`S_{t-1}` 原样印出来 | SVG 不渲染 markdown 和 LaTeX | 断言禁止 `**`；上下标用 `sub()`／`sup()` |
| 符号显示成小方块 | 字体里缺字形 | 断言拦截 |
| 字号地板没拦住 | 默认参数写死 `size=9`，绕过了 `_sz()` | 所有字号都走同一个出口 |
| 图里指向不存在的章节 | 共用图写了本课节号，L200／L300 编号不同 | `save()` 断言禁止 |
| 图例挤到下一个色块 | 估宽漏乘等宽字系数 `MONO_K` | 修基元（专题五 L20） |
| 动画相关的坑 | —— | 见 [10 · 九](10-Manim动画.md#九踩过的坑节选) |
| figink 误报数轴、长度对比条、颜色编码的等大方块 | 它只认成组的形状 | lint 只做分诊，结论以人看截图为准 |

⭐ 元规则：**修基元，不修实例。** 同一个毛病出现在八张图上，病根在共用库里。
新学到的判据做成断言，不要只写在注释里 —— 注释里的判据只在那一个文件生效。
